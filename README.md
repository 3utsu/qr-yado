# qr-yado（QRやど）

**紙でできるなら、自分でやってみよう。**
スマホを使えない高齢者でも、自宅や空き家で遍路宿を開ける仕組み。

四国遍路の道沿いでは、宿の担い手が高齢化し、空き家が増えています。一方で、歩き遍路の外国人は増えています。
qr-yado では、宿主は玄関にQRを貼り、紙を受け取るだけ。予約・チェックイン・宿泊者名簿・案内・帳簿の手続きは、外国人宿泊者のスマホと Claude が引き受けます。

> Built with Claude: Japan 2026 ハッカソン（2026/11/2〜11/8）の制作物です。このリポジトリのコードはすべて期間中に新しく書いたものです。
> 本番：https://shikoku88.3utsu.com ／ 架空データで動いています（宿泊者の名前は故人の各国の首相クラス、要員は故人の文化人。顔写真は使いません）。

## できること

| 宿泊者（スマホ・8言語） | 宿主・要員（スマホ不要） | 事業主の窓口（商工会など） | 運営者 |
|---|---|---|---|
| QRから空き状況を見て予約（貸切／相部屋、順打ち／逆打ち） | チェックインで **1人1泊1枚の紙** が自動で出る（写真・カタカナ読み・金額・受領欄・署名欄・名札） | 要員の月の予定（○×）を入れると、泊まりのある夜に当番が自動で決まる | 四国全体の需給ボード（区間×日付の表と地図） |
| 旅券を撮影 → Claude が読み取り → 本人が確認（チェックディジットはコードで検算） | 署名をもらい、現金を受け取って☑するだけ | 月の帳簿（宿泊料・日当・お財布の残り）と **freee 取引インポート用 CSV** | 詰まる区間と夜を先に知らせ、受付にブレーキ |
| 宿の案内と地域のきまりを母語で読んで同意 | 要員ごとの月の勤務予定表が紙で出る | 定期報告（2か月）の自動集計、年180日の上限、宿泊者名簿（電子・3年） | 公民館・集会所の臨時開放の候補と、依頼文・告知の下書き（Claude） |

## 設計の考え方

- **法律の義務が仕様**：住宅宿泊事業法の名簿・外国語案内・定期報告などを、宿主の作業ゼロで満たす（[docs/requirements.md](docs/requirements.md)）
- **Claude は読み取り・翻訳・分類、計算はコード**：旅券・名前の読み・案内文・依頼文は Claude、金額・日数・当番・集計・上限判定は再現性のあるコード（`src/domain/`、テストつき）
- **紙を宿主の画面にする**：宿主は操作なし。紙が人と人の交流のきっかけになる
- **手数を少なく**：仕様の言語化から実装まで Claude（チャット＋Claude Code）と進め、やり取りの回数そのものを減らす

## 構成

Cloudflare Workers（Hono / TypeScript）・D1・R2・Claude API・地理院タイル・OpenStreetMap（遍路道）・国土数値情報 P05（公民館・集会所）

```
src/
  routes/guest.ts     宿泊者の流れ（予約 → チェックイン → 同意 → 紙 → 支払った）
  routes/print.ts     紙（A4）と印刷待ちの API
  routes/operator.ts  事業主の画面
  routes/board.ts     需給ボード（表・地図）
  domain/             当番・給与・帳簿・freee CSV・MRZ・180日・定期報告・需給の計算（純粋な関数）
  claude.ts           Claude API（旅券の読み取り、カタカナ読み、翻訳、下書き）
  i18n/               宿泊者画面の辞書（en, ja, fr, de, es, nl, it, pl）
scripts/print-agent.sh  宿の機器用の印刷スクリプト（Mac：Chrome で PDF 化 → lpr）
fixtures/               架空データと見本の旅券（Utopia・SPECIMEN）
migrations/             D1 のスキーマ
```

```bash
npm install
npm run dev          # ローカル（.dev.vars に ADMIN_TOKEN を書く）
npm test             # 計算のテスト
npm run typecheck
```

- 秘密情報は Cloudflare のシークレット：`ANTHROPIC_API_KEY`、`INVOICE_API_ID`、`ADMIN_TOKEN`
- 事業主の画面・需給ボード・印刷スクリプトは `ADMIN_TOKEN` で守る。宿泊者の画面は QR から誰でも開ける
- 架空データを入れる：`/admin` →「架空データを入れる」
