## MVP の範囲

**必ず動かす（デモの核）**
1. 宿泊者：QRを読む → 空き状況を見て予約（当番の要員がいる夜だけ受ける）
2. 宿泊者：到着時にチェックイン → パスポート撮影 → Claudeが読み取り → 本人が確認 → 名簿に登録
3. 宿泊者：多言語の宿案内と地域ルールへの同意、「支払った」ボタン
4. 宿主・当番：操作なしで1人1泊1枚の紙が出る（写真・カタカナ読み・金額・受領欄・署名欄）
5. 事業主：要員の登録、月の予定、当番の自動割当、要員ごとの月の勤務予定表の印刷（D-22）
6. 事業主：月の帳簿（収入・給与）と freee 取引インポート用 CSV（D-23）
7. 運営者：定期報告の自動集計、年180日の上限判定
8. 運営者：四国全体の需給ダッシュボード（区間×日付、受付のブレーキ、公民館・集会所の臨時開放候補。架空データ）

**余裕があれば**
- 紙の予定表・申込書の読み取り（Claude）
- レシートの読み取り → 経費（インボイス照会つき）
- 相部屋の細かいマッチング条件、苦情受付

**やらない**
- オンライン決済（現金のみ）
- 本物の宿の大量登録、ネイティブアプリ
- 飲食店の予約機能（宿主が電話でつなぐ。D-14）
- 給与の税務処理（商工会へ）

## デモ動画（3分）の構成案

1. （20秒）遍路道と空き家。宿主はスマホを使えない、という課題
2. （40秒）外国人巡礼者がQRを読み、予約する（英語UI）
3. （50秒）到着 → パスポート撮影 → 名簿に自動登録 → 宿案内と同意
4. （30秒）チェックインすると、写真とカタカナ入りの紙が出る。「ジョンさん いらっしゃい！」署名と現金受領
5. （25秒）事業主側：当番と給与が自動で決まり、月の帳簿を freee に取り込む。四国全体の需給ボードで詰まりを見る
6. （15秒）まとめ：宿主は紙を受け取るだけ。四国の空き家を遍路宿に
