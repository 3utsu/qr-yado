# 法令要件とシステムでの肩代わり

qr-yado の出発点は「住宅宿泊事業法などの義務を、宿主が何もしなくても満たせること」。この表がそのまま仕様になる。
各機能を実装したら「対応テスト」列を埋める。

> ⚠️ 法令の細部（記載事項、愛媛県・宇和島市の条例による上乗せ）は実運用前に行政・専門家へ確認する。「要確認」と書いた項目は特に注意。

## 1. 住宅宿泊事業法

| 義務 | システムでの肩代わり | Claude の役割 | 優先度 | 対応テスト |
|---|---|---|---|---|
| 宿泊者名簿の備付け（氏名・住所・連絡先・宿泊日。日本に住所のない外国人は国籍・旅券番号）※記載事項は要確認 | QRからチェックイン → パスポートを撮影 → 名簿に自動登録。旅券の写しを非公開ストレージに保管 | 旅券の読み取り（構造化JSON）。人が確認する画面を必ず挟む | MVP | |
| 外国人宿泊者の快適性・利便性の確保（設備の使い方、交通、災害時の案内を外国語で） | QRの先に多言語の宿案内を表示 | 宿主が話した内容（日本語）から多言語の案内文を作る | MVP | |
| 周辺の生活環境への悪影響の防止に関する説明（騒音・ゴミ出しなど） | チェックイン時に表示し、同意ボタンで記録 | 地域ルールの多言語化 | MVP | |
| 苦情等への対応（深夜・早朝も含め常時） | 近隣住民向けQR・窓口 → 受付・管理者へ通知 | 内容の分類と一次返答 | 余裕枠 | |
| 定期報告（2か月ごと：宿泊日数、宿泊者数、延べ宿泊者数、国籍別内訳） | 名簿から自動集計 | なし（コードで集計） | MVP | |
| 年間提供日数の上限（180日。条例で短縮あり・要確認） | 予約時に超過を防ぐ | なし（コードで判定） | MVP | |
| 衛生確保・安全確保・標識の掲示 | 対象外（物理的な対応）。チェックリストとして宿主向け紙に印刷するのは可 | なし | 対象外 | |
| 家主不在型は住宅宿泊管理業者への委託が必須 | 事業化時の論点（運営者が管理業者になる想定）。ハッカソンでは構想として説明 | なし | 対象外 | |

## 2. 宿主への伝達（スマホなし）

| 必要なこと | 肩代わり | 優先度 |
|---|---|---|
| 今日・明日の宿泊者を知る | 宿主用の印刷ページ（iPadのブラウザ）→ AirPrint で紙に出す。名前・人数・金額・現金受領欄のみ。旅券番号などは載せない | MVP |
| 現金を受け取った記録 | 紙の受領欄（☑・サイン）＋ 宿主用ページの大きな「受け取った」ボタン | MVP |

## 3. 帳簿・税（余裕枠）

| 必要なこと | 肩代わり | Claude の役割 |
|---|---|---|
| 売上の記録 | 予約・受領記録から自動で売上台帳 | なし |
| 経費の記録 | レシートを撮影／スキャン → 勘定科目・税率区分・金額を読み取り → 人が確認 → freee 取込用CSV | 読み取りと勘定科目の分類 |
| 取引先の確認 | レシートの登録番号（T＋13桁）を国税庁インボイス公表システムWeb-APIで照会（ID取得済み） | なし |

### 消費税率（データとして持つ）

| 区分 | 税率 | 期間 | 備考 |
|---|---|---|---|
| 標準 | 10% | 現行 | 宿泊料、店内飲食 |
| 軽減（飲食料品） | 8% | 〜2027/3/31 | 酒類・外食を除く |
| 飲食料品 | 1% | 2027/4/1〜2029/3/31 | 2026/9/15 大綱閣議決定、**法律は未成立**。テイクアウトは1%、店内飲食は10% |

- 経費側の税率区分が必要なのは本則課税の場合。免税事業者・2割特例（個人は2026年分まで）・3割特例（個人、2027〜2028年分）・簡易課税では、経費は「合計金額と勘定科目」で足りる。読み取った税率はデータとして保存しておく。
- 課税方式の判定ロジックは実運用前に税理士・商工会に確認する。
